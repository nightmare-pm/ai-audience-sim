# Prompt 库（P1–P4）· 可直接抄进任意大模型

本文件是 `ai-audience-sim` 技能的执行弹药。每条提示词都能独立使用；跑完一轮完整模拟建议按 P1→P2→P3→P4 顺序。把 `[占位]` 替换为你的真实内容。

> 通用规则：让 AI 用**第一人称内心独白**输出，并在每个接触点明确判定"停留 / 划走"。不要只让 AI 给结论，要让它"演"出来。

---

## P1 — 选题 / 内容模拟（生成 Persona + 场景模拟）

```
你是一位[平台，如抖音]用户研究员。我的账号「[账号名]」教[你的定位，如普通人像玩游戏一样用 AI]。
下面是我准备发的一条内容：
---
[粘贴脚本 / 大纲 / 文章]
---

请做两件事：
1）生成 1–3 个具体 Persona（含年龄、职业、刷[平台]时的状态、与这条内容的关系、潜意识痛点），明确这条内容到底服务谁，拒绝"所有人"。
2）基于 5W（Who/Where/When/How/What），模拟每个 Persona 在真实场景刷到这条内容时的行为：
   - 接触点 a：看到封面
   - 接触点 b：前 3 秒
   - 接触点 c：听到核心观点
   - 接触点 d：看到结尾 CTA
   每个接触点用第一人称内心独白，并明确判定"停留 / 划走 + 原因"。
最后汇总：谁会留下、谁会划走、这条内容没接住他们哪个念头。
```

## P2 — 边界穷举（墨菲定律执行者）

```
基于下面这段内容脚本，列出 10 个会让用户划走或流失的极端场景（静音、弱网、超大字体、强光户外、0.5 秒快滑、单手、分心多任务等），
并为每条给一个**轻量降级方案**（字幕兜底 / 封面即结论 / 强画面等，不堆功能）。
---
[粘贴脚本]
---
输出格式：场景 | 为什么流失 | 降级方案。
```

---

## P3 — 封面 / 钩子校验（How 维度）

```
用 5W 检验下面这个封面/开头：
- 静音用户 0.5 秒能否读懂结论？
- 单手快速滑动时信息是否冗余？
- 小屏 + 强光下是否还清晰？
给出修改建议，并判断它在"泛兴趣路人"面前能否撑过前 3 秒。
---
[描述或贴出封面文案 / 开头台词]
---
```

## P4 — 数据回看（校准闭环，接"指标性质陷阱"）

```
这是我的后台数据：完播率 X%、3 秒留存 Y%、转粉来源 Z、粉丝画像 [简述]。
请用 5W 反推用户是在哪个环节流失的。
严格要求：
1）先区分清楚每个数字到底是 ▶播放量 还是 ❤互动量（点赞/评论），不要混用；
2）若数据不足，明确指出"需后台校准"，不要凭感觉下结论；
3）给出下一轮内容模拟应修正的假设。
```

---

## 用法提示

- **草稿期**：P1 + P2 足够（5–10 个模拟个体即可筛掉自嗨）。
- **高 stakes 发布**（如合集首集、投流素材）：把 P1 的模拟个体扩到 50–100，对应技能里"模拟一百个人"的签名做法。
- **发布后**：必跑 P4，把后台真实数据回灌，修正下一轮假设。
- 所有输出最终汇入 `assets/simulation_report.md` 模板。
