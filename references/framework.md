# 5W 场景分析 + AI 模拟 · 完整框架

本文件是 `ai-audience-sim` 技能的详细方法论库。SKILL.md 给流程，本文件给"怎么填"的具体模板、案例与边界清单。

---

## 一、为什么不用"脑补"，要用"模拟"

传统做法：在会议室/书桌前，靠 PM 或创作者的"同理心"脑补用户——自动给自己加滤镜，忽略真实场景的物理限制（地铁单手、信号忽好忽坏、耳机都没空戴、只给 0.5 秒）。脑补出来的"用户喜欢"，到真实场景基本站不住。

AI 模拟做法：把"真实世界"交给 LLM 低成本跑"平行宇宙"。LLM 是"墨菲定律执行者"——会主动把用户逼到极端场景并预演降级，而不是只走 Happy Path。成本从"数十万调研/实地走访"降到几乎为零，且可在写第一行内容前就预知成败。

**本质**：场景分析是对真实世界的敬畏，AI 是通向真实世界的一座桥。写第一行内容前就预判，不是写完再改。

## 二、5W 框架（每个维度怎么问、运营含义、例子）

| 维度 | 问自己的问题 | 在内容上的含义 | 抖音账号例子 |
|---|---|---|---|
| **Who** | 这条内容服务谁？拒绝"所有人"。给一个具体的人（年龄/职业/刷抖音状态/痛点） | 决定选题角度与口播语气 | 被 AI 焦虑困扰的 28 岁职场人 vs 想偷懒的学生 vs 想降本的商家——别一条通吃 |
| **Where** | 他在哪刷到？物理空间 | 决定信息密度与可读性 | 通勤地铁（摇晃、单手）vs 睡前躺床（沉浸）vs 工位偷看（怕被发现） |
| **When** | 什么时刻？ | 决定情绪基调 | 通勤碎片时间（不耐烦）vs 深夜（emo/求知欲） |
| **How** | 怎么刷？设备状态 | **决定钩子形式与封面**（最关键） | 静音 + 快速滑动 + 小屏 → 0.5 秒必须读懂结论 → 大字封面、红黑强对比、字幕兜底 |
| **What** | 他潜意识要什么？ | 决定落点与承诺 | "怕门槛高"→前3秒展示"不用写代码/跟着做就行"；"想要掌控感"→结尾给可复制动作 |

> **How 维度是设计规范的依据**：你账号的大字封面、强对比、字幕，不是拍脑袋，而是"静音快滑 0.5 秒读懂"的场景结论。

## 三、Persona 模板（生成具体的人，不要用抽象头像）

```
Persona 名称：[代号]
- 年龄 / 身份：[ ]
- 当前状态：[刷抖音时在做什么、情绪如何]
- 与主题的关系：[为什么会出现在这个内容前]
- 潜意识痛点：[他没说出口但驱动行为的那个点]
- 典型偏差：[他最容易在哪一秒划走]
```

**拒绝"目标所有人"**：每条内容最多服务 1–3 个 persona。通吃 = 谁都留不住。

---

## 四、三板斧（模拟力 / 边界力 / 同理心工程化）

1. **模拟力**：发布前让 AI 扮演 N 个"刷到你内容的人"，模拟他们在不同场景下的**划走 / 停留**决策，提前筛掉自嗨选题。
2. **边界力**：预演"糟糕场景"——静音刷（听不到金句）、0.5 秒划过（封面没读清）、弱网（前 3 秒卡顿）、强光户外（看不清小字）、超大字体（排版崩）。这些就是"异常流程"，对应轻量降级：字幕兜底、强画面、封面即结论。**只做轻量降级，不堆功能**——过度设计反而伤完播。
3. **同理心工程化**：把模糊感觉落成可执行标准。例如：
   - "用户怕门槛高" → 前 3 秒展示"不用写代码 / 跟着做就行"
   - "用户焦虑" → 标题给确定感（"3 步搞定"而非"浅谈 AI"）
   - "用户想要掌控感" → 结尾给可复制的操作动作

---

## 五、边缘场景清单（边界力穷举用）

发布前对照，每条给一个降级方案：
- 静音刷 → 字幕 / 画面承载关键信息，不靠声音
- 0.5 秒快滑 → 封面即结论，前 3 秒不靠铺垫
- 弱网 → 前 3 秒轻量，不在开头放重资源
- 强光户外 → 高对比配色，避免浅灰小字
- 单手操作 → 关键信息居中偏上，拇指可达
- 小屏 → 字号够大，一屏一重点
- 多任务分心 → 每 5 秒一个记忆点，断了也能接上

## 六、校准闭环（模拟 ≠ 真实）

```
模拟出假设 → 发布 → 用后台数据回灌校准 → 下一轮模拟更准
```

后台数据优先级（抖音为例）：
1. **后台数据**（完播率 / 逐秒流失曲线 / 粉丝画像 / 转粉来源）—— 唯一可靠，务必先要
2. **作品列表播放量量级** —— 判断流量池卡位（初级 0–500 / 二级 500–3000 / 三级 3000–1万 / 四级 1–10万 / 推荐池 10万+）
3. **公开作品数 × 发布日期** —— 更新节奏与断更
4. 点赞数、粉丝标签 —— 只作参考

**指标性质陷阱**：▶ 播放量 和 ❤ 点赞数 图标不同、量级不同。引用任何数字前先说明它是什么指标；上游数据被推翻时，必须回头改下游文档并加"修订记录"。

## 七、三个典型 Persona 原型（覆盖大多数内容受众）

- **焦虑新手（最该拿下）**：发了 3 条都没过 500 播放，怕"想用户"是玄学，要低门槛可抄的方法。
- **方法囤积者（最难说服）**：囤过 5 门爆款课，对"又是教用户思维"有"老生常谈"滤镜，真正缺的是"怎么真的去试"。
- **泛兴趣路人（决定前 3 秒生死）**：不做内容，纯被封面刷到，听到"做视频"就走。

> 使用时**适配，不要盲目照搬**。每条内容的具体受众要落在真实账号定位上，本原型仅作覆盖度检查。
